# Week 6: Species Distribution Models

## Core Questions

- What does a species distribution model estimate?
- How should model evaluation reflect spatial structure and sampling design?

## Topics

- Ecological niche concepts and correlative models.
- Presence-only, presence-background, and presence-absence frameworks.
- Model fitting, prediction, thresholding, and evaluation metrics.
- Spatial blocking and independent test data.

## Applied Lab

Fit a baseline species distribution model, generate predictions, evaluate model performance, and map uncertainty or sensitivity.

## Deliverable

Submit a first SDM result with methods, evaluation metrics, prediction map, and limitations.
