# Week 2: Spatial Data Foundations

## Core Questions

- How do coordinate systems, projections, resolution, and extent affect biodiversity analysis?
- When should data be represented as points, polygons, rasters, networks, or grids?

## Topics

- Coordinate reference systems and transformations.
- Vector and raster data models.
- Spatial joins, masking, aggregation, resampling, and zonal summaries.
- Consequences of mismatched spatial resolution.

## Applied Lab

Load occurrence, boundary, and raster layers; reproject data; create a common analysis grid; extract raster values to points.

## Deliverable

Submit a reproducible notebook that imports at least three spatial data layers and documents their CRS, resolution, extent, and known limitations.
